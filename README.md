# Обход на точките

Приложение за шофьорите на Алара 2000: контейнерните точки по маршрути (Банкя, Лозенец, Дианабад, Изток) на карта, с местоположението на телефона и бутон „Минах“.

- Отметките се записват в Google таблицата „Обход на точките – отметки“ (листове „Отметки“, „История“, „Шофьори“).
- Имената на шофьорите се редактират в листа „Шофьори“.
- Връзката с таблицата е в `config.js` (`apiUrl`), а скриптът за таблицата е в `apps-script/Code.gs`.
- Точките са по картите на Екобулпак; данните са в `data.js`.
- Картата е от OpenStreetMap.
